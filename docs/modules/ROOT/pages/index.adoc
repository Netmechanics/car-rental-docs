== Τι νέο υπάρχει στη 2.0

Η έκδοση `2.0` του `nmecar` αποτελεί σημαντική αναβάθμιση που εισάγει AI features, ενοποιημένη διαχείριση διαθεσιμότητας, audit logging και βελτιώσεις στο booking flow.

Σημεία που ξεχωρίζουν:

* xref:admin/ai-assistant.adoc[AI Assistant Backoffice] — AI chat assistant με deterministic analytics templates
* xref:admin/chat-widget.adoc[AI Support Chat Widget] — Floating chat widget για υποστήριξη χρηστών
* xref:booking/offline-inventory.adoc[Offline Inventory Availability] — Ενοποιημένη διαχείριση online/offline κρατήσεων
* xref:admin/audit-logs.adoc[Rental Audit Logging] — Πλήρες audit trail για αλλαγές status
* xref:booking/rentals.adoc#rental-reactivation[Rental Reactivation] — Επανενεργοποίηση ακυρωμένων κρατήσεων
* xref:booking/extras.adoc#max-quantity[Extras Max Quantity] — Περιορισμός μέγιστης ποσότητας extras

Για τη συνοπτική παρουσίαση της έκδοσης δείτε και τη σελίδα xref:release-notes/2.0.adoc[Τι νέο υπάρχει στη 2.0].

Η παρούσα τεκμηρίωση περιγράφει το `nmecar` στη γραμμή έκδοσης `2.0`, με έμφαση στις λειτουργικές δυνατότητες του συστήματος, στη διαχείριση από το {app-back} και στα νέα AI features.
