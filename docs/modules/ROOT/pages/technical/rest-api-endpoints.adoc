= REST API Endpoints

Αναλυτική περιγραφή όλων των endpoints του REST API, ομαδοποιημένα ανά controller.

Όλα τα endpoints απαιτούν authentication μέσω OAuth2. Δείτε xref:technical/rest-api.adoc[].

== Init

Αρχικά δεδομένα εφαρμογής — τοποθεσίες, τύποι οχημάτων, μέθοδοι πληρωμής, ρυθμίσεις.

[options="header",cols="1m,1m,3a"]
|===
|Method|Path|Περιγραφή

|GET|`/api/v1/init`|Επιστρέφει τα αρχικά δεδομένα για τη φόρτωση της εφαρμογής.
|===

=== Query Parameters

[options="header",cols="1m,1m,1m,3a"]
|===
|Παράμετρος|Τύπος|Required|Περιγραφή
|locale|String|Όχι|Locale (default: `el`)
|===

=== Response — InitDto

[options="header",cols="1m,1m,3a"]
|===
|Πεδίο|Τύπος|Περιγραφή
|locales|List<String>|Διαθέσιμα locales
|defaultLocale|String|Προεπιλεγμένο locale
|minDurationDays|Integer|Ελάχιστη διάρκεια ενοικίασης (ημέρες)
|nightHoursStartAt|String (time)|Ώρα έναρξης νυχτερινών ωρών (π.χ. `20:00`)
|nightHoursEndAt|String (time)|Ώρα λήξης νυχτερινών ωρών (π.χ. `10:00`)
|nightHoursCost|BigDecimal|Κόστος νυχτερινών ωρών
|timeSteps|Integer|Χρονικά βήματα ωρών παραλαβής
|priceRoundingScale|Double|Κλίμακα στρογγυλοποίησης τιμών
|vatIncluded|boolean|Αν ο ΦΠΑ περιλαμβάνεται στις τιμές
|vat|Double|Ποσοστό ΦΠΑ
|minAge|Integer|Ελάχιστη ηλικία οδηγού
|maxAge|Integer|Μέγιστη ηλικία οδηγού
|locations|List<LocationDto>|Λίστα τοποθεσιών
|minDurations|List<MinDurationDto>|Ελάχιστες διάρκειες ανά σεζόν/τοποθεσία
|vehicleTypes|List<FacetItemDto>|Τύποι οχημάτων
|paymentMethods|List<PaymentMethodDto>|Μέθοδοι πληρωμής
|driverAgeCharges|List<DriverAgeChargeDto>|Χρεώσεις ηλικιακών ομάδων οδηγού
|===

==== LocationDto

[options="header",cols="1m,1m,3a"]
|===
|Πεδίο|Τύπος|Περιγραφή
|id|Long|ID τοποθεσίας
|title|String|Τίτλος τοποθεσίας (πολυγλωσσικό)
|pickupCost|BigDecimal|Κόστος παραλαβής
|dropOffCost|BigDecimal|Κόστος παράδοσης
|soonestTime|Integer|Ελάχιστος χρόνος προετοιμασίας (ώρες)
|groupName|String|Όνομα ομάδας τοποθεσίας
|selected|Boolean|Αν είναι προ-επιλεγμένη
|googlePlaceId|String|Google Place ID
|isHotel|Boolean|Αν είναι ξενοδοχείο
|isAirport|Boolean|Αν είναι αεροδρόμιο
|===

== Fleet

Διαχείριση και ανάκτηση στοιχείων στόλου.

[options="header",cols="1m,2m,3a"]
|===
|Method|Path|Περιγραφή

|GET|`/api/v1/fleet`|Λίστα όλων των ενεργών οχημάτων
|GET|`/api/v1/fleet/\{id}`|Όχημα ανά ID
|GET|`/api/v1/fleet/groups/\{id}`|Οχήματα ανά ομάδα
|GET|`/api/v1/fleet/locations/\{id}`|Οχήματα ανά τοποθεσία
|GET|`/api/v1/fleet/tags/\{tag}`|Οχήματα ανά ετικέτα (tag code)
|GET|`/api/v1/fleet/tags/\{tag}/groups`|Ομάδες οχημάτων ανά ετικέτα
|===

=== Query Parameters (κοινοί)

[options="header",cols="1m,1m,1m,3a"]
|===
|Παράμετρος|Τύπος|Required|Περιγραφή
|locale|String|Όχι|Locale (default: `el`)
|===

=== FleetItemDto Response

[options="header",cols="1m,1m,3a"]
|===
|Πεδίο|Τύπος|Περιγραφή
|id|Long|ID οχήματος
|title|String|Τίτλος οχήματος (μοντέλο)
|description|String|Περιγραφή (μόνο στο `/\{id}`)
|group|String|Τίτλος ομάδας
|groupId|Long|ID ομάδας
|type|FacetItemDto|Τύπος οχήματος
|transmission|String|Κιβώτιο (`MANUAL`, `AUTOMATIC`)
|fuelType|String|Καύσιμο (`GASOLINE`, `DIESEL`, `HYBRID`, `ELECTRIC`, `LPG`)
|seats|Integer|Θέσεις
|doors|Integer|Πόρτες
|luggage|Integer|Αποσκευές
|images|List<String>|URLs εικόνων
|features|List<FacetItemDto>|Χαρακτηριστικά
|basicPrice|BigDecimal|Βασική τιμή
|dailyPrice|BigDecimal|Ημερήσια τιμή ομάδας
|extraHoursCost|BigDecimal|Κόστος επιπλέον ωρών
|discountAmount|BigDecimal|Ποσό έκπτωσης
|discountPercentage|long|Ποσοστό έκπτωσης (%)
|totalPrice|BigDecimal|Τελική τιμή
|===

IMPORTANT: Επιστρέφονται μόνο οχήματα όπου τόσο το Vehicle όσο και το VehicleGroup είναι ενεργά (`active = true`).

== Booking

Ροή κράτησης: search → select → reserve → sale.

=== Search

Αναζήτηση διαθέσιμων οχημάτων βάσει τοποθεσιών, ημερομηνιών και φίλτρων.

[options="header",cols="1m,2m,3a"]
|===
|Method|Path|Περιγραφή

|GET|`/api/v1/booking/search`|Αναζήτηση διαθεσιμότητας
|===

==== Query Parameters

[options="header",cols="1m,1m,1m,3a"]
|===
|Παράμετρος|Type|Required|Περιγραφή
|locale|String|Ναι|Locale
|pl|Long|Ναι|Pickup Location ID
|pd|String (datetime)|Ναι|Pickup Date (`yyyy-MM-dd HH:mm`)
|dl|Long|Ναι|Drop Off Location ID
|dd|String (datetime)|Ναι|Drop Off Date (`yyyy-MM-dd HH:mm`)
|vt|List<Long>|Όχι|Vehicle Type IDs (φίλτρο)
|===

==== Response — SearchResultDto

[options="header",cols="1m,1m,3a"]
|===
|Πεδίο|Τύπος|Περιγραφή
|pickupDate|String (datetime)|Ημερομηνία παραλαβής
|pickupLocation|LocationRefDto|Τοποθεσία παραλαβής
|pickupLocationCost|BigDecimal|Κόστος παραλαβής
|pickupNightHourCost|BigDecimal|Κόστος νυχτερινής παραλαβής
|dropOffDate|String (datetime)|Ημερομηνία παράδοσης
|dropOffLocation|LocationRefDto|Τοποθεσία παράδοσης
|dropOffLocationCost|BigDecimal|Κόστος παράδοσης
|dropOffNightHourCost|BigDecimal|Κόστος νυχτερινής παράδοσης
|routeCost|BigDecimal|Κόστος διαδρομής
|rentalDays|int|Ημέρες ενοικίασης
|chargeableDays|int|Χρεώσιμες ημέρες
|extraHours|double|Επιπλέον ώρες
|minDuration|int|Ελάχιστη διάρκεια (ημέρες)

|anyLocationHotel|boolean|Αν κάποια τοποθεσία είναι ξενοδοχείο
|anyLocationAirport|boolean|Αν κάποια τοποθεσία είναι αεροδρόμιο

== Mail

Αποστολή emails από φόρμες επικοινωνίας.

[options="header",cols="1m,2m,3a"]
|===
|Method|Path|Περιγραφή

|POST|`/api/v1/mail/contact`|Αποστολή φόρμας επικοινωνίας

== Google Services

Ανάκτηση στοιχείων Google Place (αξιολογήσεις, λεπτομέρειες).

[options="header",cols="1m,2m,3a"]
|===
|Method|Path|Περιγραφή

|GET|`/api/v1/gservices/\{locale}/rating`|Αξιολόγηση Google Place
|GET|`/api/v1/gservices/\{locale}/details/\{placeId}`|Λεπτομέρειες Google Place
|===

Το endpoint `details` επιστρέφει JSON με επιπλέον πεδίο `embedMapUrl` για ενσωματωμένο χάρτη.
