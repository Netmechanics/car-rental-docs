= AI Assistant Backoffice
:revdate: Αύγουστος 2026

Το {app-back} διαθέτει AI chat assistant βασισμένο στο Jmix 3 AI Tools add-on που επιτρέπει στους operators να ανακτούν analytics και να λαμβάνουν υποστήριξη μέσω φυσικής γλώσσας.

== Πρόσβαση

Ο AI Assistant είναι διαθέσιμος μέσω του μενού *AI Analytics* στο {app-back}. Η πρόσβαση ελέγχεται μέσω του ρόλου `BasicAccessRole` που περιλαμβάνει το `AiToolsChatUserRole`.

image::ai-analytics.png[alt="AI Analytics",width="85%"]

== Deterministic Analytics Templates

Το σύστημα προτιμά pre-built analytics templates έναντι generic exploration για consistency και accuracy.

=== Διαθέσιμα Templates

[options="header",cols="1m,3a"]
|===
|Template|Περιγραφή

|BOOKINGS_BY_STATUS
|Κατανομή κρατήσεων ανά status (Reserved, Rented, Cancelled, Completed)

|BOOKINGS_BY_PICKUP_LOCATION
|Κατανομή κρατήσεων ανά τοποθεσία παραλαβής

|BOOKINGS_REVENUE_BY_CREATED_MONTH
|Έσοδα ανά μήνα δημιουργίας κράτησης

|RECENT_BOOKINGS_SAMPLE
|Δείγμα πρόσφατων κρατήσεων

|PAYMENT_METHOD_SAMPLE
|Κατανομή μεθόδων πληρωμής

|BOOKING_FULL_REPORT
|Πλήρης αναφορά κρατήσεων με όλα τα πεδία

|BOOKING_EXTRAS_BREAKDOWN
|Ανάλυση extras ανά κράτηση
|===

=== Πώς λειτουργεί

Το `NmcrAnalyticsTemplateTool` είναι custom `JmixAiTool` που:

. Αναγνωρίζει analytics requests από τον χρήστη
. Επιλέγει το κατάλληλο template
. Εκτελεί το template με παραμέτρους
. Επιστρέφει structured results

IMPORTANT: Τα templates προτιμώνται έναντι generic exploration. Αν ο χρήστης ζητήσει "δείξε μου κρατήσεις ανά status", το σύστημα θα χρησιμοποιήσει το `BOOKINGS_BY_STATUS` template αντί να κάνει generic query.

== Entity Filter

Το `NmcrAiAvailableEntityFilter` ελέγχει ποια entities εκτίθενται στο AI:

=== Approved Entities

* Booking
* Pricing
* Fleet entities (Vehicle, VehicleGroup, VehicleItem)

=== Excluded Entities

* CMS entities (Posts, Menus)
* Users
* Settings (SystemSettings, MailSettings)
* Customer entities

IMPORTANT: Το entity filter εφαρμόζεται αυτόματα. Ο χρήστης δεν μπορεί να ζητήσει πρόσβαση σε excluded entities μέσω του AI chat.

== AI Diagnostics

Πλήρες audit trail για κάθε αλληλεπίδραση AI μέσω του `AiDiagnosticsLog` entity.

=== Events

[options="header",cols="1m,3a"]
|===
|Event|Περιγραφή

|SUCCESS
|Επιτυχής αλληλεπίδραση

|NO_DATA
|Δεν βρέθηκαν δεδομένα για το query

|VALIDATION_FAILURE
|Validation error στα δεδομένα

|TOOL_FAILURE
|Error κατά την εκτέλεση tool
|===

=== Προβολή Diagnostics

* *List View:* `AiDiagnosticsLogListView` — Προβολή όλων των diagnostic entries
* *Detail View:* `AiDiagnosticsDialogSupport` — Λεπτομέρειες συγκεκριμένου entry
* *Menu:* Administration → AI Diagnostics Logs

== Configuration

=== Ρυθμίσεις AI (Runtime UI)

Ο AI provider, το μοντέλο, το API key και οι παράμετροι (temperature, max tokens) ρυθμίζονται runtime μέσω της οθόνης xref:admin/settings-ai.adoc[*Ρυθμίσεις AI*] (Administration → Ρυθμίσεις AI).

Οι τιμές αποθηκεύονται στη βάση (`NMCR_AI_SETTINGS`) και εφαρμόζονται κατά την εκκίνηση της εφαρμογής μέσω του `DynamicAiConfiguration`.

=== Application Properties (fallback)

Οι `application.properties` παρέχουν fallback τιμές όταν δεν υπάρχει row στη βάση:

[source,properties]
----
spring.ai.openai.api-key=${SPRING_AI_OPENAI_APIKEY:}
spring.ai.openai.chat.model=gpt-5.4-mini
spring.ai.openai.chat.temperature=0.1
spring.ai.openai.chat.max-completion-tokens=4096
----

IMPORTANT: Οι ρυθμίσεις από το UI (`NMCR_AI_SETTINGS`) υπερισχύουν των `application.properties` μέσω του `@Primary` `DynamicAiConfiguration` bean.

=== Feature Toggle

Δεν υπάρχει feature toggle για τον AI Assistant. Είναι πάντα ενεργός όταν το Jmix AI Tools add-on είναι present.

== Security

* *Access Control:* Μόνο χρήστες με `BasicAccessRole` (περιλαμβάνει `AiToolsChatUserRole`)
* *Entity Filter:* Αυτόματο filtering βάσει `NmcrAiAvailableEntityFilter`
* *Audit Trail:* Όλες οι αλληλεπιδράσεις καταγράφονται στο `AiDiagnosticsLog`
