= Τι νέο υπάρχει στη 2.0
:revdate: Ιούλιος 2026

Η έκδοση `2.0` εισάγει προαιρετική αναζήτηση μικτής διαθεσιμότητας για το booking site.

== Αναζήτηση κατόπιν αιτήματος

Όταν ο διαχειριστής ενεργοποιήσει τη νέα global ρύθμιση, τα αποτελέσματα μπορούν να περιλαμβάνουν:

* άμεσα κρατήσιμα οχήματα (`AVAILABLE`, `bookable=true`),
* μη διαθέσιμα οχήματα για αίτημα προσφοράς (`UNAVAILABLE`, `bookable=false`).

Τα δεύτερα εμφανίζονται με σαφή σήμανση *Κατόπιν αιτήματος* και οδηγούν στην υπάρχουσα φόρμα quote/request αντί στη ροή κράτησης.

== Ασφάλεια ροής κράτησης

Η διαθεσιμότητα του search response δεν αποτελεί άδεια κράτησης. Τα βήματα `booking/select` και `booking/reserve` επανελέγχουν το αποτέλεσμα και επιστρέφουν conflict για μη κρατήσιμο όχημα.

== Συμβατότητα και rollout

Η νέα ρύθμιση είναι απενεργοποιημένη από προεπιλογή. Έτσι, αμέσως μετά την αναβάθμιση, το search συνεχίζει να επιστρέφει μόνο διαθέσιμα οχήματα μέχρι να γίνει ρητή ενεργοποίηση από το Backoffice.
