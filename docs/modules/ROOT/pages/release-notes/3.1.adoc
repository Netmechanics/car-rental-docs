= Τι νέο υπάρχει στη 3.1
:revdate: Οκτώβριος 2026

Η έκδοση `3.1` προσθέτει μαζική αλλαγή της λειτουργίας διαθεσιμότητας στη λίστα των ομάδων οχημάτων. Δεν απαιτείται ενέργεια για την αναβάθμιση: δεν αλλάζει η βάση δεδομένων και οι υπάρχουσες ρυθμίσεις μένουν ως έχουν.

== Λίστα ομάδων οχημάτων

* Νέες στήλες *Λειτουργία διαθεσιμότητας* και *Δηλωμένο πλήθος*. Η ομάδα που κληρονομεί τη λειτουργία από τις ρυθμίσεις συστήματος εμφανίζει «Από ρυθμίσεις».
* Πολλαπλή επιλογή γραμμών με checkbox.
* Νέο κουμπί *Αλλαγή λειτουργίας διαθεσιμότητας* πάνω από τη λίστα, για αλλαγή της λειτουργίας σε όλες τις επιλεγμένες ομάδες μαζί.

Δείτε τη σελίδα xref:fleet/vehicle_groups.adoc#vehicle-groups-list[Λίστα ομάδων και μαζική αλλαγή λειτουργίας διαθεσιμότητας].

== Κανόνας δηλωμένου πλήθους

Η λειτουργία `ALLOTMENT` απαιτεί δηλωμένο πλήθος. Ο κανόνας ισχύει πλέον και για τη μαζική αλλαγή: αν λείπει το πλήθος, καμία ομάδα δεν αλλάζει.

== Σημειώσεις

* Η κενή λειτουργία στο παράθυρο σημαίνει κληρονομικότητα από τις ρυθμίσεις συστήματος.
* Η αλλαγή εφαρμόζεται αμέσως και επηρεάζει τη διαθεσιμότητα από εκείνη τη στιγμή.
